# Skybreak

A browser prototype of a roguelike jet dogfighting game. Pick a location and a jet, fly a branching map of missions that ends in a boss, collect gear that changes how you fight, and bring home credits for new jets and skill points for the skill tree.

**Play:** open `index.html` in a browser, or use the GitHub Pages link for this repository.

## Controls (mouse aim)

| Input | Action |
| --- | --- |
| Mouse | Aim. The jet flies toward the circle. In cockpit view it moves the stick |
| W / S | Throttle. Keep holding W at 100% for afterburner |
| A / D, Q / E | Roll, rudder |
| Left mouse / Space | Guns |
| Right mouse / R | Missile, after lock-on |
| F / middle mouse | Flares |
| V (hold) | Free look |
| C | Chase / cockpit view |
| P / Esc | Pause |

A gamepad and touch controls also work. Progress is saved in your browser.

Built with [three.js](https://threejs.org/) r128, loaded from cdnjs.
